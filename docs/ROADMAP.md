# Roadmap

Estimates assume one developer, part-time, working with Claude. Each phase ends with a playable build and acceptance criteria. No phase starts until the previous deliverable works.

| Phase | Deliverable | Estimate | Status |
|---|---|---|---|
| 0 Foundation | Repo, docs, movement contract, tests | 1–2 wks | **done** |
| 1 Movement prototype | Capsule Cub on Graybox Block | 3–5 wks | **in progress** |
| 2 Parkour slice | Wall-run, wall-jump, slide, roll, hang/shimmy, balance; rooftop course; feel tuning | 2–3 mo | |
| 3 Skateboarding | Skate states, tricks, grinds on Path3D rails, the Lines system, graybox skatepark | 2–3 mo | |
| 4 Cub and the hometown | Character model, rig, animation set, first neighbourhood, NPCs | 3–4 mo | |
| 5 Story and music | Missions, dialogue, rhythm sections, opening of Chapter 1 | 3–4 mo | |
| 6 Vertical slice | One polished district | 2–3 mo | |
| 7 Full production | All chapters | 18–30 mo | |
| 8 Polish and release | Performance, accessibility, Steam release | 4–6 mo | |

## Phase 1 acceptance criteria
- [x] Walk, jog and sprint with acceleration; variable jump; coyote time; jump buffer
- [x] Vault, step-up, standing climb, mid-air ledge grab; hard landing
- [x] Third-person camera with collision, speed-based FOV and auto-recentre
- [x] Keyboard and controller bindings defined in code
- [x] The graybox level is generated by a Blender script, and collision comes through the import
- [x] Headless tests pass (`tools/run_tests.sh`, exit code 0)
- [x] 60 FPS on the baseline (M1, 16 GB, 1600×900, vsync), measured by `tests/capture.tscn`
- [ ] **Creator playtest:** run the rooftop row start to finish without stopping; jump feels like it responds within one frame
- [ ] In-game rebinding menu (deferred to the settings UI)
